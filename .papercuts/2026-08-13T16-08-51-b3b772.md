A delegated task told a subagent to invoke the mattpocock-skills:writing-great-skills skill with the Skill tool. That skill sets disable-model-invocation, so the call fails with 'cannot be used with Skill tool' and the subagent stalls with no work done. A task prompt cannot require a subagent to invoke a user-invoked skill. Fix: note in the writing-great-skills docs, or in agent-dispatch guidance, that a user-invoked skill must be read by the main thread and its rules passed into the prompt.
